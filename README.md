# 🏨 Online Hotel Booking

A full-stack hotel listing web application built with Node.js, Express.js, MongoDB, EJS and Bootstrap.

## 🌐 Live Demo

👉 [Live Website](https://online-hotel-booking-biff.onrender.com)

## ✨ Features

- User Signup, Login & Logout
- Authentication & Authorization
- Create, Edit & Delete Listings
- Image Upload
- Reviews & Review Authorization
- Search & Price Filters
- Location Geocoding
- Interactive Maps
- Responsive UI
- MongoDB Atlas Integration
- Deployed on Render

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript, EJS, Bootstrap  
**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose, MongoDB Atlas  
**Authentication:** Passport.js, Express Session  
**APIs:** Geoapify, Leaflet  
**Deployment:** Render
